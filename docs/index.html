Same firm, two segmented markets, one enterprise value. When a firm's stock and bonds diverge from their historical relationship, which market — if either — predicts the other's convergence?
I set out to test whether the slower bond market leads stocks.
Step 1 · Establish the benchmark
Fact

First, define the normal equity–bond relationship

REquityi,t = αt + βt RBondi,t + εi,t
Equity return = fitted bond relationship + residual
Historical beta is positive & stable
Same-firm corr
0.42
Pooled OLS beta
≈ 1.26
Expanding β: 1.10–1.33, always positive
Estimated using data through t−1 only
The residual from that line = Dislocation
R̂Equityi,t = α̂t + β̂t RBondi,t
⟶
Di,t = REquityi,t − R̂Equityi,t
Dislocation = Actual Equity Return − Bond-Implied Equity Return
+D equity outran credit  ·  −D equity lagged credit
A dislocation is a statistical deviation, not automatically a mispricing.
Estimate the normal β on prior data, then measure each firm's residual from it.
Step 2 · Test the direction
FactInterpretation

How does the dislocation normalize?

Di,t = REquityi,t − R̂Equityi,t
D > 0 equity outran credit  ·  D < 0 equity lagged credit  — the regressions use the continuous signal (both signs)
Original hypothesis · does equity correct?
REquityi,t+1 = λt + γ Di,t + εi,t+1
γ = −0.027
t = −1.44 · NOT SIGNIFICANT
No statistically significant equity convergence
If γ < 0, a positive dislocation would predict equity falling back toward credit.
Empirical finding · credit catches up
RBondi,t+1 = λt + δ Di,t + εi,t+1
δ = +0.030
t = +2.84 · STATISTICALLY SIGNIFICANT
Dislocation significantly predicts next-month bond catch-up
If δ > 0, equity outrunning credit predicts the bond subsequently moving the same way.
Signal-month fixed effects · firm & month clustered standard errors
The evidence points to credit catch-up, not significant equity correction.
But Dt is constructed from both equity and bond returns — next I test whether this result is mechanical.

Step 4 · From signal to trade
Implementation

Trade the expected credit catch-up

+ D equity outran credit ⟶ LONG corporate credit
− D equity lagged credit ⟶ SHORT corporate credit
Monthly construction
1  benchmark on data ≤ t−1→ 2  firm-level dislocation→ 3  rank into quintiles→ 4  long Q5 / short Q1→ 5  hold 1 month, rebalance
Weighting
Within firm: AO-weight bonds into one credit return. Across firms: equal-weight issuers per leg.
Return
Duration-matched Treasury-adjusted bond return — approximates credit convergence; not perfectly rate-neutral.
Portfolio
Dollar-neutral long/short; monthly rebalance.
Equity already moved; the trade targets the bond's expected catch-up.

When NOT to trade

Economic / event
M&A / cap-structure · creditor-friendly dilution · debt-funded buyback · rating distress / default
Implementation
transaction costs / turnover · cash-bond shorting · HY liquidity
Model failure
regime change · signal decay · unexplained corporate events
Counterexample — HPP: a large dilutive equity raise can push equity down while bonds stay ~flat for valid reasons — not necessarily delayed credit adjustment.  Dislocation ≠ mispricing.
Use the model as a systematic screen, then verify the economic story before trading the divergence.

2 · Core method
Benchmark & dislocation — estimated on past data only:
REquityi,s = αt + βt RBondi,s, s ≤ t−1  ⟶  Di,t = REquityi,t − R̂Equityi,t
Next-month bond predictive — controls for both current returns:
RBondi,t+1 = λt + β1 RBondi,t + β2 REquityi,t + εi,t+1
Coefficients scoring month t use only data through t−1 — no look-ahead. Month FE · firm & month clustered SEs.
