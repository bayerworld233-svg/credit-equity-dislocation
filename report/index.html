Two weighting layers

Within firm: multiple bonds → amount-outstanding-weighted firm credit return.

Across firms: equal-weight issuers in each leg — so large debt issuers don't dominate.

Return

Duration-matched Treasury-adjusted (credit-excess) return — to approximate a credit-convergence trade, not a rates bet. Approximately, not perfectly, rate-neutral.

Equity already moved; if equity leads credit, trade the bond's expected catch-up.

When would I NOT trade the signal?

  • M&A / cap-structure change
  • Equity dilution (creditor-positive)
  • Debt-funded buyback / M&A
  • Rating / distress / default
  • Transaction costs & turnover
  • Cash-bond shorting / HY liquidity
Counter-example — HPP: a large dilutive equity raise makes equity↓ while bonds≈flat economically correct, not delayed adjustment.
A systematic screen for convergence candidates, then an event check — not a mechanical trade on every divergence.

Appendix · A2 — Signal & no-look-ahead method

Contemporaneous relationship & the frozen dislocation signal

Expanding estimation (look-ahead-free)

eqi,s = αt + βt·bdi,s + ε,  over all s ≤ t−1

Pooled OLS, ≥24-month minimum history, single common β, no firm/month FE. α̂t, β̂t then score month t out-of-sample.

Stability checks

Monthly cross-sectional corr: mean 0.29, 96.9% of months positive. Pooled β = 1.26 (t ≈ 147). Expanding βₜ ∈ [1.10, 1.33], all positive.
